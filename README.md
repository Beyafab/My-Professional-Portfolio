# Cloud, Network & Cybersecurity Portfolio

A lightweight, modern, and high-performance portfolio website built with pure HTML5, CSS3, and JavaScript. Designed with zero external dependencies for fast load times and easy static hosting on services like AWS S3.

## 🚀 Features

- **Modular Architecture:** Separated HTML structure, CSS styling, and JavaScript logic for clean maintainability.
- **Responsive & Accessible:** Fully adaptable design for screens from desktop down to mobile devices.
- **Scroll Animations:** Built-in section reveal effects using native `IntersectionObserver`.
- **Lightweight & Fast:** Zero frameworks or external build tools required.

---

## 🛠️ Tech Stack & Focus Areas

- **Cloud:** AWS (S3, CloudFront, IAM)
- **Systems:** Linux (System Administration, CLI Workflows)
- **Networking:** CCNA foundations, Routing & Switching, IP Networking
- **Security:** Network Security, CyberOps fundamentals
- **Programming:** Python for scripting and automation
